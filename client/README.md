# Layerzero — Client Frontend

The frontend interface for Layerzero built with React, TypeScript, Vite, Tailwind CSS, and shadcn/ui. Handles user authentication state, document upload workflows, URL submission, model selection, real-time SSE token streaming, and client-side PDF export.

---

## Technical Design Decisions (Why & How)

### Why React + Vite?
* **Why:** Traditional bundlers like Webpack have slow cold starts and rebuild latency during dev.
* **Solution:** Vite leverages native browser ES modules during development for instant HMR (Hot Module Replacement) and fast production builds.

### Why Server-Sent Events (SSE) Streaming Reader?
* **Why:** Standard `fetch` wait states force the UI to remain blank for 5-10 seconds while the LLM generates output.
* **Solution:** The client reads the `text/event-stream` response line-by-line using a chunk reader (`ReadableStreamDefaultReader`).
* **Impact:** Renders summary tokens on screen as they are generated by the backend LLM, providing real-time feedback.

### Why Client-Side PDF Export (`jsPDF`)?
* **Why:** Rendering PDFs on the backend (e.g. via Puppeteer or pdfkit) consumes server CPU/RAM and adds unnecessary network roundtrips.
* **Solution:** `jsPDF` converts generated Markdown summaries into downloadable PDF files directly inside the user's browser.

### Why `httpOnly` Cookie Credentials (`credentials: 'include'`)?
* **Why:** Storing JWT tokens in client state or `localStorage` exposes them to XSS attacks.
* **Solution:** All API calls send `credentials: 'include'`, letting the browser automatically transmit the `httpOnly` JWT cookie without exposing access token values to JavaScript.

## Tech Stack

| Component | Technology | Rationale |
|---|---|---|
| **Framework** | React 18 + Vite | Fast dev HMR and component reactivity |
| **Language** | TypeScript | Type safety for API models, props, and streaming buffers |
| **Styling** | Tailwind CSS + shadcn/ui | Utility-first styling with accessible UI components |
| **Markdown Rendering** | `remark-gfm` + `rehype-raw` | Renders rich GitHub-flavored markdown summaries securely |
| **PDF Export** | `jsPDF` | In-browser PDF generation from summary text |

## Running Locally

1. **Install dependencies:**
   ```bash
   cd client
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
